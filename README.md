# FAANG Interview Prep

A free, step-by-step playbook for landing big tech internships, new grad roles, and early-career offers.

**Read it as a website: [jugaldb.github.io/faang-interview-prep](https://jugaldb.github.io/faang-interview-prep/)**

**Track your progress: [Interactive roadmap](https://jugaldb.github.io/faang-interview-prep/roadmap/)**

Built for students, new grads, and engineers with 0 to 3 years of experience, including international students targeting the US, India, the UK, and Europe. Every page is a set of steps with direct links and copy-paste templates.

## Start here

1. Read [Start here](docs/start-here.md). Pick a 4, 8, 12, or 16 week plan and a weekly hour budget.
2. Open the [interactive roadmap](https://jugaldb.github.io/faang-interview-prep/roadmap/) and tick tasks as you go. Progress saves in your browser.
3. Pick 3 to 5 target companies from [Companies](docs/companies/index.md) and use their pages in the last 2 to 3 weeks before each interview.

## Data credits

The company question lists are built from two open datasets of LeetCode company tags. Thank you to both authors.

- [liquidslr/leetcode-company-wise-problems](https://github.com/liquidslr/leetcode-company-wise-problems): company-wise CSVs for the last 30 days, 3 months, 6 months, and all time.
- [snehasishroy/leetcode-companywise-interview-questions](https://github.com/snehasishroy/leetcode-companywise-interview-questions): company-wise lists in the same windows, updated through July 2026 (per the repo description).

Tags are user-reported. Treat frequency as a signal, not a promise. Every other fact on the site credits its source inline.

## Run the site locally

You need Python 3.

```bash
git clone https://github.com/jugaldb/faang-interview-prep.git
cd faang-interview-prep
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

Open the local address that `mkdocs serve` prints. Pages reload when you save a file in `docs/`.

## Regenerate the company pages

Company pages in `docs/companies/` are generated. Do not edit them by hand.

1. Clone both datasets next to this repo.

    ```bash
    git clone https://github.com/liquidslr/leetcode-company-wise-problems.git ../lcw
    git clone https://github.com/snehasishroy/leetcode-companywise-interview-questions.git ../sr
    ```

2. Merge them into `data/questions.json`.

    ```bash
    python3 scripts/build_question_data.py --lcw ../lcw --sr ../sr
    ```

3. Build the pages. This rewrites `docs/companies/*.md`, `docs/companies/more/*.md`, and the Companies block of the `mkdocs.yml` nav.

    ```bash
    python3 scripts/build_company_pages.py
    ```

To change a company's process, rounds, or reported questions, edit `data/companies/<slug>.json` and run step 3 again.

## Contributing

- Open an issue for a dead link, a changed interview process, a closed program, or an outdated date.
- Pull requests are welcome. Every new fact needs a source link, and every link must load.
- Keep the house style: plain markdown, short sentences, steps that start with a verb, relative links between pages, no em dashes, no emojis.
- Company data changes go in `data/companies/*.json`, not in the generated pages.
- The site deploys to GitHub Pages from `main` through `.github/workflows/deploy.yml`.
