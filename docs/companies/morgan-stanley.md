## Interview process

### New grad

1. **Apply.** Apply through the Students & Graduates opportunity search (technology business area). Official 3-step path: Explore, Apply, Interview.
2. **Online assessment.** India campus (2025 to 2026 reports are for the 2027 SDE intern OA; no first-hand new grad OA post found): SHL/AMCAT test of about 111 minutes: Debugging (7 questions, 15 min, fix 1 to 2 bugs in C++/Java/Python snippets), Aptitude (24 interactive questions in 36 min: drag-and-drop scheduling, graph plotting, logical reasoning), Coding (3 questions, 60 min, LeetCode medium in April 2026; a Sept 2026 on-campus candidate reported 2 coding problems). US (secondary sources only): HackerRank coding test (2 to 3 problems, 60 to 90 min) plus a HireVue recording with 2 to 3 behavioral prompts.
3. **Technical interview(s).** India on-campus Sept 2026 (2027 SDE intern hiring, used here as the closest campus data): technical round with introduction, project deep dive (RAG architecture follow-ups), and a backtracking DSA question. US secondary guides describe a 45 to 60 minute technical screen with live coding.
4. **Behavioral and HR / Superday.** India on-campus Sept 2026 (2027 SDE intern hiring): behavioral round (hackathon impact, why GPA is lower, is AI reliable in fintech) and HR round (projects, interest in post-grad studies, relocation); 6 of 12 interviewed were selected. US secondary guides describe a Superday of 3 to 5 back-to-back interviews mixing coding, possibly design, and behavioral.

### Intern

1. **Online assessment.** India SDE intern (2027 batch, April 2026, SHL/AMCAT): Debugging 7 Q / 15 min, Aptitude 24 Q / 36 min, Coding 3 Q / 60 min (shuffle array, Delete and Earn variant, count ways to choose k zeros). Aug 2025 on-campus intern OA: debugging (choose Java, C or C++; save your code), a G+ reasoning test (scheduling, probability, percentages), and 3 coding questions in 60 minutes. Sept 2026 on-campus OA on SHL: debugging (7 questions), aptitude, and 2 coding problems (XOR with array traversal, a 3D knapsack).
2. **Interviews.** Sept 2026 on-campus (2027 intern): 3 rounds, technical (project + DSA), behavioral, HR. Code to Give hackathon is another entry route with its own OA (candidate posts; location not stated) (Feb 2025: debugging 10 Q / 20 min, aptitude 24 Q / 40 min, coding 3 Q / 60 min).
3. **Offer.** No official or first-hand 2025 to 2026 data on return offers or the intern-to-full-time timeline was found.

### With 1 to 3 years of experience

Lateral hiring (2 to 4 yrs, Associate) 2025 to 2026, mostly India (Mumbai, Bangalore; several posts do not state location): HackerRank test (70 to 90 min) mixing Java MCQs, a SQL query, a Spring Boot debugging task with unit tests, and a coding question; then usually 4 rounds: 2 technical (resume deep dive, DSA such as Group Anagrams, Spiral Matrix, Next Permutation, LRU Cache; Java, Spring Boot, Spring Security, microservices, SQL, Kubernetes, LLD like Snake and Ladder or a full Controller-Service-DAO service on paper; HLD like Design Uber), 1 techno-managerial with a VP or Executive Director (concurrency, Kafka, deadlocks, production checks), 1 HR/culture fit (expected CTC and justification). Round 2 is sometimes in person. Weak Spring Security or Java depth was the stated reason for two Jan 2026 rejections. US mid-level (interviewing.io): recruiter call, optional 45 min HackerRank, then a 3 to 4 hour onsite with language-specific coding, DSA, a non-coding OOP interview and a behavioral round with the hiring manager; most teams skip system design; hiring is decentralized and often takes over 6 weeks.

## Online assessment

- **Platform:** SHL/AMCAT (India campus 2026), HackerRank (lateral Java roles; per secondary sources also US)
- **Format:** India campus: 3 sections, about 111 min: Debugging (7 Q, 15 min), interactive Aptitude (24 Q, 36 min), Coding (3 Q, 60 min, LeetCode medium). Lateral HackerRank: 70 to 90 min with Java MCQs, SQL, Spring Boot debugging, 1 coding question.
- **Notes:** Coding questions are often reworded LeetCode classics (House Robber, Delete and Earn, Subarrays with K Different Integers). The debugging section requires saving your code. Aptitude items are interactive, not plain MCQ, in 2026.

Prepare with [How to pass an OA](../online-assessments/strategy.md) and compare formats in [OA formats by company](../online-assessments/company-oa-formats.md).

## Coding rounds

- **Rounds:** New grad/intern: 1 technical round with DSA (India campus); US Superday reportedly includes 1 to 2 coding interviews. Experienced: 2 technical rounds.
- **Style:** LeetCode easy to medium, classic problems (stock buy/sell, anagrams, spiral matrix, LRU cache, next permutation), recursion/backtracking, plus Java/Spring and SQL depth for Java roles. Some interviewers rush straight to code.
- **Environment:** Online video rounds; some second rounds in person (Mumbai, India); LLD sometimes written on paper.
- **Graded on:** Correct working code and complexity; language fundamentals; SQL; explaining project architecture; how you work through a scenario (official prep page).
- **Reported focus topics:** arrays and strings, DP basics (House Robber, Delete and Earn, knapsack), sliding window and two pointers, recursion and backtracking, linked lists, monotonic stack, LRU cache / hash map design, core Java (collections, GC, exceptions, concurrency), Spring Boot and Spring Security for Java roles, SQL joins, date functions, window functions, OOP and LLD, debugging and aptitude (India OA)

Run every practice problem through [the 45-minute framework](../coding/interview-framework.md) and the [code quality rubric](../coding/code-quality.md).

## Beyond LeetCode

Debugging section (fix bugs in short code snippets) and interactive aptitude test in India OAs; Spring Boot debugging task where you fix a small web app until unit tests pass (Associate Java OA, April 2025); Java MCQs and SQL queries; LLD written on paper; Code to Give hackathon (Feb 2025 candidate posts; location not stated).

## System design

New grad: little or no system design; OOP/LLD questions possible. 0 to 3 yrs (India Associate): LLD (Snake and Ladder; Controller-Service-DAO-Entity service on paper; SOLID), HLD (Design Uber, explain your project's architecture), microservices (distributed tracing, API gateway, CI/CD), Kafka consumer groups. interviewing.io notes most US teams do not run a system design interview.

Start with [who needs system design](../system-design/index.md), then the [framework](../system-design/framework.md).

## Behavioral

**Framework:** Five core values: Do the Right Thing, Put Clients First, Lead with Exceptional Ideas, Commit to Diversity & Inclusion, Give Back ([official page](https://www.morganstanley.com/about-us/morgan-stanley-core-values))

**What they look for:**

- Who you are and what motivates you; whether you understand the business and the job (official prep page)
- Knowing your resume well enough to discuss everything on it without reading it (official)
- A compelling reason for this industry, this firm and this division (official)
- Knowledge of 1 or 2 areas of the industry you can discuss with conviction (official)
- How you work through a scenario rather than always having the right answer (official)
- Collaboration and passion for learning (official)

**Questions to prepare:**

- Why Morgan Stanley? What do you know about the firm and its stock? (Backend engineer HR round, Nov 2025)
- How would you react if asked to report to someone junior to you? (Backend engineer, Nov 2025)
- How would you react if you were not promoted? (Backend engineer, Nov 2025)
- Do you solve first and ask later, or understand from others first? (Backend engineer, Nov 2025)
- Why is your CGPA lower than other candidates'? (SDE intern 2027, Sept 2026)
- Is using AI in a fintech company reliable? (SDE intern 2027, Sept 2026)
- Tell us about a hackathon you joined and how your solution solves a real problem (SDE intern 2027, Sept 2026)

Build your answers with the [story bank](../behavioral/story-bank.md). Company detail: [behavioral guide](../behavioral/other-companies.md).

## Tips

- For India campus OAs, rehearse all three sections under time: 7 debugging fixes in 15 minutes, 24 interactive aptitude items in 36 minutes, 3 coding problems in 60 minutes; save code in the debugging section.
- Practice reworded classics: House Robber, Delete and Earn, Subarrays with K Different Integers and Shuffle the Array all appeared in disguise.
- Learn your resume line by line; the official prep page says to articulate everything without reading it.
- Prepare a specific 'why Morgan Stanley, why finance, why this division' answer and 1 or 2 industry topics you can discuss with conviction, as the official prep page advises.
- For Java roles, revise Spring Boot, Spring Security, multithreading and SQL window functions; two Jan 2026 rejections came from Spring Security or Java depth, not DSA.
- Practice one LLD on paper end to end (Controller, Service, DAO, Entity) and one game LLD (Snake and Ladder).
- If AI or RAG projects are on your resume, expect architecture follow-ups and a question on AI reliability in fintech.
- Read the five core values and map one story to each before behavioral and HR rounds.

## 4-week plan for Morgan Stanley

Do this after you finish a core list like [Grind 75 or NeetCode 150](../coding/problem-lists.md).

- [ ] Week 1: Solve problems 1 to 20 from the most frequent list. Time-box each at 30 minutes.
- [ ] Week 2: Solve problems 21 to 40. Re-solve any you failed in week 1 without looking.
- [ ] Week 3: Solve the signature problems and every reported question above. Do 2 timed mock interviews.
- [ ] Week 4: Write 8 stories for the Five core values: Do the Right Thing, Put Clients First, Lead with Exceptional Ideas, Commit to Diversity & Inclusion, Give Back round. Do 2 full mock loops. Review the online assessment and system design notes above.
