## Interview process

### New grad

1. **Application.** New grad postings appear in spring, not fall: 'Software Engineer New Grad' and 'iOS Software Engineer New Grad' posted Apr 28 to 30, 2026 (Seattle or SF, hybrid 3 days/week on-site, base $128K to $142K, <1 yr full-time experience). Postings ask for CS fundamentals plus foundational AI/ML awareness (LLM APIs, model evaluation).
2. **Recruiter screen.** 30 min. Background, motivation, 'why Airbnb'. Hello Interview G8 guide says the first call may be with a recruiter or hiring manager.
3. **Online assessment (CodeSignal, often auto-sent).** Changed in 2026: Jul to Sep 2026 reports say Airbnb emails a CodeSignal Industry Coding Assessment right after you apply (one Sep 2026 candidate: 'probably sent automatically'). One progressive build in a single codebase with 4 levels; the next level unlocks only after the current level's tests pass; scored out of 600; screen share and mic stay on for the whole test. Reported tasks: banking system, cloud storage / in-memory file system, task management system. A perfect score still ended in rejection a week later for one Aug 2026 candidate. Reports are labeled Software Engineer or SSE; not confirmed for the new grad postings specifically.
4. **Technical screen.** 60 min live coding on CoderPad. Hello Interview says one or two problems; candidate reports usually describe one long multi-part problem (DP, graph, simulation). Code must run: interviewing.io says 'Pseudocode is not allowed' and you must write working code and run it; Hello Interview says production quality code, not pseudocode sketches.
5. **Virtual onsite.** Coding (60 min, multi-part, production-quality code), Code Review (60 min, review about 3 GitHub pull requests and leave written comments; Hello Interview says it replaced the second coding round in 2024, and a Mar 2026 candidate confirmed 3 PRs), plus a system design or technical-experience round depending on level. At G7 the design bar is lower, but candidates report it still appears in some loops.
6. **Core values interview.** Separate gate, often scheduled after the technical onsite. interviewing.io calls these 'Host' interviews 'conducted by non-engineers' and says 'fail these and you won't get an offer'; Hello Interview lists it as a 30-min mandatory gatekeeper. Questions map to the four values (Champion the Mission, Be a Host, Embrace the Adventure, Be a Cereal Entrepreneur). A Jan 2026 candidate (PracHub) said it ended early after about 20 minutes.
7. **Team match and offer.** Post-onsite conversations with hiring managers. A Mar 2026 candidate reported hearing team match can take months (claim, not measured).

### Intern

1. **Application window.** Short fixed windows. Summer 2026 SWE intern posting: Dec 8 to 17, 2025 and Jan 12 to 21, 2026 (first window 'offers the best chance to be considered'), 12 weeks, BS/MS with 1 to 2 semesters left (graduating Dec 2026 to Jun 2027). Official internship page: USA summer program is 12 weeks (May to August), applications December to February, open to full-time students with at least one semester remaining.
2. **Recruiter screen.** Short call.
3. **Technical interviews.** Reported: two 45-min coding interviews on Zoom plus CoderPad (DSA, edge cases, complexity), LeetCode medium to hard. Source is a Nov 2025 Glassdoor intern review seen only in search snippets (UNVERIFIED).
4. **Values interview.** Reported: one 45-min cross-team values interview (collaboration, ownership, communication, product sense). Same UNVERIFIED Glassdoor source. Example values prompts reported: most memorable trip, an organization you admire, a time you stood up for something.
5. **Decision.** About two weeks from scheduling to decision per the same UNVERIFIED snippet. Official page: Airbnb's goal is for interns to join full time, but conversion depends on 'individual performance and business-need'.

### With 1 to 3 years of experience

For 1 to 3 yrs the loop is the same centralized process (interviewing.io: everyone follows one process, grading shifts by level). Expect a 60-min system design screen or onsite round (Miro/Excalidraw) and a Technical Experience deep dive on one past project (scope and impact decide G7 vs G8). G8 loop per Hello Interview (2026): recruiter/HM screen, CoderPad coding screen, system design screen, onsite coding, code review, system design, 30-min core values. India hiring (Bangalore, 'Work from Anywhere (India)') uses the same format: a Mar 2026 India SWE loop had a topological-sort screen, two 45-min coding rounds with strict timeboxing and a dry run at the end.

## Online assessment

- **Platform:** CodeSignal Industry Coding Assessment (progressive, 4 levels), reported Jul to Sep 2026 and often auto-sent after applying; live coding screens use CoderPad
- **Format:** CodeSignal: one task, 4 levels, score out of 600, screen share and mic on. Reported tasks: banking system (create_account, deposit, transfer; top_spenders; scheduled payments; merge accounts), cloud storage / in-memory file system (add, copy, prefix and suffix search; users with capacity; compress and decompress), task management system (add/update/get; search and priority sort; user quotas with expiring assignments; overdue report). Live screen: 1 problem, 60 min, must run.
- **Notes:** Keep level 1 data structures flexible because later levels reuse them; a failing test can come from an earlier level's data handling (Jul 2026). Scores reported: 400/600 (Jul 2026), 440 stuck on level 3 (Sep 2026), 600/600 then rejected (Aug 2026). Timestamp ordering is the trap in the scheduled-payments level. Time is the main constraint.

Prepare with [How to pass an OA](../online-assessments/strategy.md) and compare formats in [OA formats by company](../online-assessments/company-oa-formats.md).

## Coding rounds

- **Rounds:** 1 screen + 1 onsite coding round for most loops (second coding round replaced by code review since 2024); some 2026 India loops still had 2 coding rounds
- **Style:** LeetCode medium to hard with an Airbnb-flavored story (bookings, stays, menus, ski runs, accounts). Heavy on DP, graphs, union-find, simulation. Multi-part: interviewers add follow-ups once part 1 runs
- **Environment:** CoderPad for the coding screen (Hello Interview; interviewing.io says Airbnb uses CoderPad for technical interviews); code review round uses GitHub-style PRs; CodeSignal for the OA
- **Graded on:** Working, tested code within the hour; clean names and modular functions; reasoning about complexity; ability to extend for follow-ups. Passing all test cases mattered more than reaching the optimal approach in one Mar 2026 report
- **Reported focus topics:** Dynamic programming (subset/knapsack style, bitmask over items), Graphs: DAG DP, topological sort, BFS shortest path, Union-find, Simulation and state machines (board games, water pouring), Greedy scheduling with deadlines, OOP and incremental system builds for the CodeSignal OA (bank, file storage, task manager), String processing, Code review: spotting bugs, edge cases, readability, Booking/reservation system design (double booking, search, hot partitions)

Run every practice problem through [the 45-minute framework](../coding/interview-framework.md) and the [code quality rubric](../coding/code-quality.md).

## Beyond LeetCode

Code Review round: about 3 pull requests, comment on bugs first, then edge cases, performance, readability; a Jan 2026 candidate (PracHub) said the interviewer stayed mostly silent while they annotated the code. Technical Experience round: deep dive on past projects to set level. CodeSignal progressive OA (bank, file storage, task manager) that tests OOP and incremental design more than algorithms.

## System design

Not the focus for interns. New grad (G7): light or absent; some candidates still get a design or technical-experience round. 1 to 3 yrs (G8): a 60-min design screen plus a 60-min onsite design. Reported prompts: booking platform that prevents double bookings plus search, with a hot-partition follow-up for a big event (Jan 2026); group chat like WhatsApp (Jan 2026); Hello Interview list: chat/messaging, job scheduler, notification system, reservation system.

Start with [who needs system design](../system-design/index.md), then the [framework](../system-design/framework.md).

## Behavioral

**Framework:** Four core values: Champion the Mission, Be a Host, Embrace the Adventure, Be a Cereal Entrepreneur ([official page](https://careers.airbnb.com/life-at-airbnb/))

**What they look for:**

- An authentic reason to join tied to belonging, travel, hosting, or community
- Hospitality toward teammates (Be a Host)
- Ownership and creative problem solving under constraints (Cereal Entrepreneur)
- Curiosity and resilience after setbacks (Embrace the Adventure)
- Community involvement, mentoring, volunteering (new grad postings list this as a plus)

**Questions to prepare:**

- Why Airbnb?
- How have you contributed to a community, or what volunteer work have you done? (Mar 2026 report)
- Tell me about a conflict, failure, tight deadline, or complex project you owned (technical experience round, Jan 2026)
- Describe a time you stood up for something you believe in
- Anything you really want to do in the future?
- Tell me about your most memorable trip

Build your answers with the [story bank](../behavioral/story-bank.md). Company detail: [behavioral guide](../behavioral/other-companies.md).

## Tips

- Practice CodeSignal-style 4-level builds (in-memory bank, file storage, task manager) under a 90-minute clock: in 2026 the Airbnb OA often arrives minutes after you apply, and you need most levels done to score well.
- Practice writing code that runs on the first try in CoderPad: Airbnb rejects pseudocode, and passing the interviewer's tests is the bar.
- Drill DP and graph problems wrapped in long product stories (stays, menus, ski runs); a Mar 2026 candidate called the coding rounds 'super heavy on DP'.
- Expect a follow-up after part 1 works, so leave 10 to 15 minutes and structure code with small functions you can extend.
- Prepare for the code review round by reviewing real PRs: comment on correctness first, then edge cases, tests, naming.
- Write 1 or 2 stories per core value, including one about community or volunteering; the values round can reject you on its own.
- Apply in the first intern window (early December); the 2026 posting said the first window gives the best chance.
- Check sponsorship before applying: the Summer 2026 intern posting said Airbnb is 'unable to sponsor visas for this position'. Use the H-1B check from Jugal's post: https://jugaldb.substack.com/p/how-to-check-if-a-company-sponsors
- New grad roles posted in late April 2026, so keep applying in spring instead of assuming Airbnb only hires in fall.

## 4-week plan for Airbnb

Do this after you finish a core list like [Grind 75 or NeetCode 150](../coding/problem-lists.md).

- [ ] Week 1: Solve problems 1 to 20 from the most frequent list. Time-box each at 30 minutes.
- [ ] Week 2: Solve problems 21 to 40. Re-solve any you failed in week 1 without looking.
- [ ] Week 3: Solve the signature problems and every reported question above. Do 2 timed mock interviews.
- [ ] Week 4: Write 8 stories for the Four core values: Champion the Mission, Be a Host, Embrace the Adventure, Be a Cereal Entrepreneur round. Do 2 full mock loops. Review the online assessment and system design notes above.
