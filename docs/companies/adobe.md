## Interview process

### New grad

1. **Application.** Adobe careers (Workday). Official 5-stage flow: Application, Talent Partner conversation, Hiring Manager interview, Skills assessments and team interviews (for engineers: coding challenges, system design discussions, or portfolio reviews), Offer.
2. **Online assessment.** US SWE intern loop (Nov 2024, Workfront team, Salt Lake City, virtual; written up Sep 2026): 3 LeetCode mediums on HackerRank. India campus (2024 to 2025): 2 coding questions (strings/hashmap, sliding window) plus MCQs on OS, DBMS, OOP. India SDE-1 OA (Aug 2025): tree DP with rerooting (diameter endpoints).
3. **Technical interview(s).** US: 1 live problem-solving round (a medium string problem). India campus: interview 1 is DSA (medium-hard, brute force to optimal, complexity, 'what if input is huge'); interview 2 is a simple system design plus OOP (why interfaces, inheritance examples) and HashMap internals.
4. **Hiring manager / managerial round.** Behavioral and team fit: a project you liked, a time you messed up, pressure, why Adobe. Followed by an HR offer call.

### Intern

1. **OA.** US (Nov 2024 report): HackerRank, 3 LeetCode mediums. India: the 2025 Adobe India Hackathon round 1 ran on Unstop (very theoretical MCQs plus coding). The 2026 'Adobe University Hackathon' OA (Aug 2026) had MCQs on a roughly 1-minute timer each plus 2 DSA questions (count nodes whose value plus children's values equals k; largest binary number by concatenation); other 2026 OA reports include a C++ OOP drone-energy simulation and a 'Hall of Shifting Tiles' problem. The 2026 platform was not confirmed.
2. **Technical interview.** US: 1 live coding round. FY27 (Sep 2026): a candidate reported a HackerRank technical interview with a bug-fix question and a code-review question.
3. **Hiring manager fit.** Behavioral, background, and the team.
4. **Conversion.** India product and SWE interns receive PPOs to MTS-1 (Aug 2025 and Aug 2026 reports).

### With 1 to 3 years of experience

MTS-2 (about 2 to 4 yrs) is the main 0 to 3 yr loop: 3 to 5 rounds, often a single-day hiring drive (Noida/Bangalore) or spread over 2 weeks. R1: DSA on HackerRank, code must pass 6 to 8 custom test cases (Merge Intervals, LFU Cache), plus OOP/SQL/caching talk. Language-depth round for the JD stack: C++ (smart pointers, rule of five, const member functions, producer-consumer with condition variables, implement shared_ptr) or Java (abstract class vs interface, threads, Spring Boot, SQL joins). LLD round (in-memory file system, warehouse space allocation, configuration management service, rate limiter, autocomplete). HM round with HLD (URL shortener, HLD of your own project). Director round: deep project defense, on-call incidents, manager conflict, sometimes coding ('give this to Claude and optimize it', Aug 2026). Frontend MTS-2: JS event loop, React typeahead with debouncing, React Fiber, pub/sub machine coding, frontend system design.

## Online assessment

- **Platform:** HackerRank (US intern/new grad and India experienced); Unstop for the 2025 Adobe India Hackathon (university); platform for the 2026 'Adobe University Hackathon' not confirmed.
- **Format:** US intern/new grad: 3 LeetCode mediums. India campus: 2 coding questions plus CS MCQs (OS, DBMS, OOP). Hackathon OA: timed MCQs (about 1 min each in 2026) plus 2 CP-style coding questions; one 2026 problem was a C++ OOP simulation.
- **Notes:** Reported OA problems: tree diameter endpoints with rerooting DP (Aug 2025), 'Hall of Shifting Tiles' (Aug 2026), drone energy simulation with inheritance and virtual functions (Aug 2026), candy-selling optimization (Jul 2025), largest binary number by concatenation (Aug 2026).

Prepare with [How to pass an OA](../online-assessments/strategy.md) and compare formats in [OA formats by company](../online-assessments/company-oa-formats.md).

## Coding rounds

- **Rounds:** New grad: 1 to 2 technical rounds. MTS-2: 2 to 4 rounds that include coding.
- **Style:** LeetCode medium to hard, often 2 to 3 problems per 45 to 60 min (one MTS-2 round: 2 mediums and 1 hard in 45 min). Language-specific implementation tasks (shared_ptr, thread-safe queue) and classic problems (Trapping Rain Water, Minimum Window Substring, Coin Change, Maximum Product Subarray).
- **Environment:** HackerRank (CodePair) with runnable custom test cases; in-person drives at Noida/Bangalore offices. 2026: some rounds are Claude-assisted or ask you to optimize with Claude. Official AI policy (Adobe careers page 'AI and your hiring experience'): do not use AI recording, live scribing or conversation-prompting tools during hiring conversations unless invited.
- **Graded on:** Running code that passes test cases, optimization from brute force, edge cases, explaining your thinking aloud, and language depth for the role's stack.
- **Reported focus topics:** Arrays, strings and sliding window (Minimum Window Substring, Merge Intervals), Trees and tree DP (diameter, rerooting, org-tree propagation), Cache design (LRU, LFU, pluggable eviction), LLD: file system, warehouse, config service, autocomplete, rate limiter, C++ internals (smart pointers, rule of five, memory leaks) or core Java (OOP, concurrency, Spring Boot), Concurrency (producer-consumer, thread-safe queues, locks), DP (Coin Change, knapsack variants, subset counts), Frontend: JS event loop, debounce/throttle, React internals

Run every practice problem through [the 45-minute framework](../coding/interview-framework.md) and the [code quality rubric](../coding/code-quality.md).

## System design

New grad: light, a simple system design plus OOP questions in interview 2 (India campus). MTS-2 (0 to 3+ yrs): a dedicated LLD round (in-memory file system, configuration management service, warehouse allocation, autocomplete top-K, rate limiter, LRU with pluggable eviction strategies) and HLD inside the HM round (URL shortener, design your current project). CS-1 adds a full HLD and a director-level design question (sales-related HLD, Aug 2026).

## Behavioral

**Framework:** Adobe values (2023): Create the Future, Own the Outcome, Raise the Bar, Be Genuine. Official hiring page asks for specific examples with measurable impact. Adobe's official 'AI and your hiring experience' page (2026) cites Create the Future and Be Genuine, so the 2023 values are still in use; it asks candidates to show concrete examples of how AI amplified their impact, in their own voice. ([official page](https://blog.adobe.com/en/publish/2023/03/07/evolving-adobes-values-culture))

**What they look for:**

- Clear thinking aloud and steady communication under pressure
- Ownership: defend each technical decision in your projects
- Measurable impact from past work (official tip)
- Handling production incidents and on-call
- Collaboration and disagreement with managers or other teams
- How you use AI tools day to day, with concrete examples of impact (2026 rounds and the official AI-in-hiring page)

**Questions to prepare:**

- Tell me about a project you liked.
- Tell me about a time you messed up.
- How do you deal with pressure?
- Why Adobe?
- Describe an on-call incident you handled.
- Tell me about a conflict with your manager.
- Describe a production issue you faced.
- How do you use AI daily? If you wrote one Claude skill, what would it do?

Build your answers with the [story bank](../behavioral/story-bank.md). Company detail: [behavioral guide](../behavioral/other-companies.md).

## Tips

- Write complete, runnable code fast: Adobe rounds run on HackerRank with custom test cases, sometimes 2 to 3 problems in 45 min.
- Prepare deep language questions for the stack in the JD (C++ memory and concurrency, or Java OOP and threads); a C++-heavy resume was rejected for a Java role after a bullet-by-bullet review.
- Practice 4 LLDs: in-memory file system, LRU/LFU with pluggable eviction, rate limiter, and autocomplete with top-K.
- Treat the director round as a real round: defend every design choice, have an on-call story and a manager-conflict story ready, and expect a coding question.
- Practice reviewing and improving AI-generated code; 2026 Adobe rounds have asked candidates to work with Claude, and the 2027 intern and new-grad postings stress AI-assisted development with validation.
- For the FY27 intern cycle, practice bug-fix and code-review exercises in addition to LeetCode (reported HackerRank format, Sep 2026).
- Indian students: register for the Adobe India Hackathon on Unstop; its OA mixes hard theory MCQs with coding.
- If rejected, apply to a different team rather than the same requisition; the same-position cooling period is 6 months.
- Do not run AI note-takers, live scribing or prompting tools during Adobe interviews unless invited (official policy), and prepare concrete stories of how AI improved your work.
