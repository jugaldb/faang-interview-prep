# Every Ascend post by topic

Subscribe at [jugaldb.substack.com](https://jugaldb.substack.com) to get new posts by email.

> **Watch out:** Older posts can carry closed job links, passed deadlines and tools that have moved. Where a post and this site disagree, the paired page has the October 2026 version.

## How to use this page

1. Find the topic you are working on.
2. Read the post for the reasoning and Jugal's own results.
3. Do the steps on the paired site page.
