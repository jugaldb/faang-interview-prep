# Problem lists: which one to do

For anyone deciding what to solve on LeetCode. When you finish this page you will have one list, a week-by-week order, and a date to switch to company-tagged problems.

> **Tip:** You need one core list, not five. "I solved 120 LeetCode problems and still got into Amazon, Google, and Meta" ([post](https://jugaldb.substack.com/p/i-cleared-amazon-google-and-meta)). The skill being tested is spotting the pattern fast, not volume.

## How to use each list

### Grind 75 and Grind 169 (5-minute setup)

1. Open [Grind 75 in the author's order](https://www.techinterviewhandbook.org/grind75?order=all_rounded&grouping=weeks). The default view sorts by difficulty, which puts all 9 Hards in the last week. `order=all_rounded` rotates topics every week.
2. Set "weeks" to the weeks until your first interview. Set "hours" to the hours per week you will really study.
3. Check that the page says the plan fits your schedule.
4. Bookmark the URL. Your settings live in the URL.
5. Tick problems as you finish. Progress is saved only in that browser. Do not clear site data or switch browsers.
6. Use each problem's minutes (15 to 45) as your timer. If you still need longer after 20 to 30 problems, spend a week on [topics](topics.md) before continuing (the [Grind FAQ](https://www.techinterviewhandbook.org/grind75/faq) gives the same advice).

Ready-made schedules (counts computed with the site's own scheduler):

```text
2 weeks x 15 h/week (39 problems):  https://www.techinterviewhandbook.org/grind75?weeks=2&hours=15&order=all_rounded
4 weeks x 15 h/week (71 problems):  https://www.techinterviewhandbook.org/grind75?weeks=4&hours=15&order=all_rounded
8 weeks x 8 h/week (75 problems):   https://www.techinterviewhandbook.org/grind75?order=all_rounded
12 weeks x 8 h/week (111 problems): https://www.techinterviewhandbook.org/grind75?weeks=12&hours=8&order=all_rounded
8 weeks x 20 h/week (all 169):      https://www.techinterviewhandbook.org/grind75?weeks=8&hours=20&order=all_rounded
All 169, no schedule:               https://www.techinterviewhandbook.org/grind75?mode=all
```

### NeetCode 150 and NeetCode 250

1. Open the [NeetCode roadmap](https://neetcode.io/roadmap). It draws NeetCode 150 as a tree of 18 topics, starting at Arrays & Hashing.
2. Go in roadmap order. Do not start a topic until the one above it is done. Jugal: "It's sequenced so each topic sets up the next one" ([post](https://jugaldb.substack.com/p/want-a-job-in-the-next-30-days-use)).
3. Work 20 to 30 minutes alone before you open the video.
4. After each solve, write the pattern in your [tracking sheet](how-to-practice.md#tracking-sheet-template).
5. Solve Premium-only problems free on NeetCode. All 6 LeetCode Premium problems in Blind 75 (7 in NeetCode 150) have free copies, for example [Meeting Rooms](https://neetcode.io/problems/meeting-schedule).
6. On NeetCode 250, the extra 100 problems (32 Easy, 54 Medium, 14 Hard) add more reps per topic. If you already know the basics, use them only for your two weakest topics.
7. Prefer tracking on LeetCode? Save the public [NeetCode 150 list](https://leetcode.com/problem-list/rr2ss0g5/) to your account (user-made, shows when logged in).

### LeetCode study plans

1. Log in before you open a plan. Logged-out views hide Premium items, so counts look short.
2. LeetCode 75 is not the LeetCode version of Blind 75. Only 10 problems overlap, and 45 of its 75 are not in NeetCode 250 at all.
3. Use Top Interview 150 instead of NeetCode 150, not on top of it. They share 77 problems.
4. Use a topic plan (DP, Binary Search, Graph Theory) for 2 to 3 weeks when one topic keeps failing.
5. Skip the "Amazon Spring '23" and "Google Spring '23" high-frequency plans. They are from 2023.

### Sean Prashad LeetCode Patterns

1. Beginners: open the Beginner Roadmap tab (68 problems in 11 phases, each with a one-line hint). Read the hint only after 30 minutes on your own.
2. Experienced: use the Experienced roadmap (Sean's version of Blind 75). If stuck for 15 minutes, open the Helpful Tips tab. It maps cues to approaches: a sorted input array, for example, points to binary search or two pointers.
3. Use the company column for free company signal. Each problem lists the companies that asked it and how often.
4. Filter by pattern to drill a weak area. Read the source data in the [repo](https://github.com/seanprashad/leetcode-patterns) if you want the hints offline.

### Striver sheets (takeUforward Prep Hub)

1. Open the [Prep Hub](https://takeuforward.org/prep-hub). Pick A2Z if you are starting from zero, the SDE Pattern Sheet if you know the basics, Striver's 75 for the last month.
2. Striver uses his own problem names. Search for the LeetCode version: "Kadane's Algorithm" is [Maximum Subarray](https://leetcode.com/problems/maximum-subarray/). "Sort an array of 0's 1's and 2's" is Sort Colors.
3. The free tier covers the free questions. TUF+ is paid and adds full practice and premium questions.
4. Old links to the classic "SDE Sheet" now redirect to the 179-problem SDE Pattern Sheet.

### Blind 75

1. Practice it through [NeetCode's Blind 75 page](https://neetcode.io/practice/practice/blind75): one video per problem, Premium problems free.
2. Read the [original 2018 post](https://www.teamblind.com/post/new-year-gift-curated-list-of-top-75-leetcode-questions-to-save-your-time-oam1oreu) only for history. Its author, Yangshun Tay, later built Grind 75 as the updated, prioritized version.
3. Blind 75 has no stack, backtracking, or greedy section. NeetCode 150 fills that gap.
4. Track on LeetCode with the public [Blind 75 list](https://leetcode.com/problem-list/oizxjoit/).

## Which list should you do?

1. **Test your basics (1 hour).** Solve [Two Sum](https://leetcode.com/problems/two-sum/), [Valid Parentheses](https://leetcode.com/problems/valid-parentheses/), [Reverse Linked List](https://leetcode.com/problems/reverse-linked-list/) and [Maximum Depth of Binary Tree](https://leetcode.com/problems/maximum-depth-of-binary-tree/). Give each 15 minutes, no help. Solved 3 or 4: you know the basics. Solved 2 or fewer: start as a beginner and read [topics](topics.md) first.
2. **Count your weeks.** Count weeks until your first online assessment or phone screen, not the onsite. Count honest hours per week. Benchmark from the [Tech Interview Handbook study plan](https://www.techinterviewhandbook.org/coding-interview-study-plan/): about 3 months at 11 hours a week for thorough prep.
3. **Pick your row and column below.** Write the list name and end date at the top of your tracking sheet.
4. **Adjust for your track** with the rules after the table.
5. **Commit for 2 weeks** before you judge the list. Switching lists in week one restarts your clock.

| Your level | 2 weeks | 4 weeks | 8 weeks | 12 weeks | 16+ weeks |
|---|---|---|---|---|---|
| Beginner | LeetCode 75 for 2 weeks. Ask the recruiter for more time | Sean Prashad Beginner Roadmap (68) | Beginner Roadmap, then the 51 Grind 75 problems it does not cover | Beginner Roadmap, then the 111 NeetCode 150 problems it does not cover | NeetCode 250, or Striver A2Z for Indian placements |
| Knows the basics | Grind, 2 weeks x 15 h (39) | Grind, 4 weeks x 15 h (71), or Blind 75 at 3 a day | NeetCode 150 at 3 a day, or Grind 75 default (8 x 8 h) | Grind 75, then the 92 NeetCode 150 problems it does not cover | NeetCode 250, then the 47 Grind 169 problems it does not cover |
| 0 to 3 years experience | Grind, 2 weeks x 15 h | Grind, 4 weeks x 15 h | Grind 169 at 8 weeks x 20 h | Grind 169, then company tags | Grind 169 plus NeetCode 250 extras, then company tags |

> **Watch out:** Every plan ends with company-tagged problems and mocks: the last 4 days of a 4-week plan, the last 2 to 3 weeks of a 12 to 16-week plan. Size your list so it finishes before that.

Track rules:

- **Intern (first or second year):** LeetCode 75, then Grind 75. LeetCode 75 has zero Hards, which matches where most first-years start. See [intern interviews](../internships/intern-interviews.md).
- **New grad:** use the "knows the basics" row. Jugal's view on NeetCode 150: "For new grad and most mid-level roles, getting through this list is enough on its own" ([post](https://jugaldb.substack.com/p/want-a-job-in-the-next-30-days-use)). The data mostly agrees: it covers 30 to 36 of the top 50 recent tagged problems at Google, Meta, Amazon and Microsoft.
- **0 to 3 years experience:** use the experience row and start [system design](../system-design/index.md) in parallel.
- **Google target:** add the LeetCode DP plan and the Hard list on the [Google page](../companies/google.md). NeetCode 250 covers 44 of Google's top 50 recent tags, the most of any list.
- **Meta target:** after NeetCode 150, add these recent Meta tags it misses: [Subarray Sum Equals K](https://leetcode.com/problems/subarray-sum-equals-k/), [Minimum Remove to Make Valid Parentheses](https://leetcode.com/problems/minimum-remove-to-make-valid-parentheses/), [Next Permutation](https://leetcode.com/problems/next-permutation/), [Max Consecutive Ones III](https://leetcode.com/problems/max-consecutive-ones-iii/), [Minimum Size Subarray Sum](https://leetcode.com/problems/minimum-size-subarray-sum/), [Find Peak Element](https://leetcode.com/problems/find-peak-element/), [Random Pick with Weight](https://leetcode.com/problems/random-pick-with-weight/), [Find First and Last Position of Element in Sorted Array](https://leetcode.com/problems/find-first-and-last-position-of-element-in-sorted-array/), plus Valid Word Abbreviation and Binary Tree Vertical Order Traversal (both Premium). Details on the [Meta page](../companies/meta.md).
- **Data analyst, data engineer, data scientist:** SQL 50 at 4 to 5 a day (2 weeks). Then [DataLemur](https://datalemur.com/questions) (freemium: $15 a month or $60 a year for premium) or [takeUforward SQL 75](https://takeuforward.org/prep-hub/sql---75-frequently-asked-interview-questions). Then the two pandas plans if there is a Python round. Add LeetCode 75 if the job also has a DSA round.

Then CSES Sorting and Searching (35), Dynamic Programming (23), Graph Algorithms (36) and Tree Algorithms (16), reading the matching chapter of the free [CSES book](https://cses.fi/book/book.pdf) first. - **Indian campus placements:** Striver A2Z or the SDE Pattern Sheet. Use Love Babbar 450 only if your college's rounds are GfG-style.

## Recommended progression

### Default: knows the basics, 12 weeks, 2 to 2.5 hours a day

1. Weeks 1 to 4: Grind 75 in All Rounded order (about 3 a day).
2. Weeks 5 to 9: the 92 NeetCode 150 problems not in Grind 75. On the NeetCode page, skip anything you already ticked in Grind.
3. Week 10: Hards. Google targets: the Hard list on the [Google page](../companies/google.md). Everyone else: the NeetCode 150 Hards you skipped (21 total).
4. Weeks 11 to 12: top 30 to 40 company-tagged problems you have not done, plus 4 [mock interviews](mock-interviews.md).
5. Total: about 200 to 220 problems, plus re-solves.

### Beginner: 16 weeks, about 2 hours a day

1. Weeks 1 to 4: Sean Prashad Beginner Roadmap (68 problems in 11 phases).
2. Weeks 5 to 10: NeetCode 150 in roadmap order. About 111 are new after the Beginner Roadmap, so about 2 to 3 a day.
3. Weeks 11 to 13: the extra 100 of NeetCode 250 for your two weakest topics, or the 63 Grind 169 problems not in NeetCode 150.
4. Weeks 14 to 15: company tags for your top target, 30 to 40 Medium and Hard.
5. Week 16: 4 to 6 timed mocks. Re-solve every problem you failed.
6. Total: about 230 to 280 problems.

### 8 weeks

1. Weeks 1 to 7: NeetCode 150 at 3 a day. If you only have about 1.2 hours a day, use Grind 75's default 8 weeks x 8 hours instead.
2. Week 8: company top 20 to 30, plus 2 to 3 mocks.

### 4-week crunch

1. Days 1 to 24: Grind at 4 weeks x 15 hours (71 problems), or Blind 75 on NeetCode at 3 a day.
2. Days 25 to 28: company "last 30 days" or "last 3 months" list, top 15 to 20 Medium and Hard. 2 mocks.

### 2-week emergency (phone screen already booked)

1. Days 1 to 11: Grind at 2 weeks x 15 hours (39 problems). Under a week left? Do the 36 problems above instead.
2. Days 12 to 14: company "last 30 days" list, top 10 to 15. One mock.
3. If you can, ask the recruiter for more time. Recruiters rarely mind which week you interview ([interviewing.io on postponing](https://interviewing.io/blog/its-ok-to-postpone-your-interviews-if-youre-not-ready)).

### Experienced refresh (0 to 3 years), 6 to 8 weeks

1. Grind 169 compressed: [8 weeks x 20 hours](https://www.techinterviewhandbook.org/grind75?weeks=8&hours=20&order=all_rounded) returns all 169.
2. Then company tags. Meta: include its Premium-only tags (Valid Word Abbreviation, Binary Tree Vertical Order Traversal, Nested List Weight Sum).

### Jugal's 60-day pattern roadmap

A pattern-first alternative to a list. Source: [I Cleared Amazon, Google, and Meta With Only 120 LeetCode Problems](https://jugaldb.substack.com/p/i-cleared-amazon-google-and-meta), with problems per pattern in his [Company Wise DSA patterns](https://jugaldb.notion.site/Company-Wise-DSA-patterns-26caf2117b83808eb7b2efae6afd15dc) page.

| Days | Patterns | Rule for the block |
|---|---|---|
| 1 to 10 | Fast and slow pointers, two pointers, prefix sum, sliding window (fixed and variable), then cyclic sort | 3 to 4 problems per pattern. Move on only when you can name the pattern from the problem statement alone |
| 11 to 20 | Linked list reversal, matrix manipulation, monotonic stack, bitwise XOR | Learn each template. A 45-minute monotonic stack problem should drop under 10 minutes |
| 21 to 35 | BFS and DFS, trees (level order, construction, height, root-to-leaf, ancestors), graphs (topological sort, union-find, shortest paths, MST), backtracking | The heaviest block. Give it the most time |
| 36 to 45 | DP in layers: take/not take, unbounded, LIS, grids, strings, stocks, partition | Go in order. By day 45, name the DP family within 60 seconds |
| 46 to 52 | Modified binary search, top K with k-way merge, two heaps, overlapping intervals | Do top K and k-way merge together (both use heaps) |
| 53 to 58 | Company sprint: the 4 patterns your target favors (list in the post) | 2 to 3 timed problems per pattern |
| 59 to 60 | Mock interviews only | 45 minutes, one problem, out loud. No new problems |

> **Tip:** In the graph block, learn Dijkstra first. The [Tech Interview Handbook graph page](https://www.techinterviewhandbook.org/algorithms/graph/) rates Bellman-Ford, Floyd-Warshall, Prim and Kruskal as almost never asked.

### Free, without Premium (about 15 minutes to set up)

1. Clone the dataset (470 companies, last updated Aug 16, 2026):

    ```text
    git clone --depth 1 https://github.com/liquidslr/leetcode-company-wise-problems.git
    ```

2. Make `done.txt` with every problem you solved, one LeetCode URL or slug per line.
3. Save the script below as `company_top.py` and run it on your company's "Six Months" file. It prints the top unsolved problems by frequency.
4. Cross-check the top 20 against the second dataset, [snehasishroy](https://github.com/snehasishroy/leetcode-companywise-interview-questions) (July 2026 snapshot, rows sorted by ID, so the script sorts them for you). Prefer problems that appear in both.
5. For a Premium-only problem, search NeetCode for a free copy, or read the statement in interview reports and solve it in your editor.
6. Stop after 30 to 50 problems.

```python
"""Print the top company-tagged LeetCode problems you have NOT solved yet.

Works with both open datasets:
  liquidslr:     <Company>/3. Six Months.csv   (columns: Difficulty, Title, Frequency, Link, ...)
  snehasishroy:  <company>/six-months.csv      (columns: ID, URL, Title, Difficulty, Frequency %, ...)

Usage:
  python3 company_top.py "leetcode-company-wise-problems/Google/3. Six Months.csv" done.txt 40 no-easy

done.txt: one LeetCode problem URL or slug per line (what you already solved).
no-easy (optional): hide Easy problems, which are the noisiest tags.
"""
import csv
import sys

path = sys.argv[1]
done_file = sys.argv[2] if len(sys.argv) > 2 else None
limit = int(sys.argv[3]) if len(sys.argv) > 3 else 40
skip_easy = len(sys.argv) > 4 and sys.argv[4] == "no-easy"


def slug(text):
    text = text.strip().rstrip("/")
    return text.split("/problems/")[-1].split("/")[0] if "/problems/" in text else text


def freq(row):
    value = row.get("Frequency") or row.get("Frequency %") or "0"
    return float(value.rstrip("%") or 0)


done = set()
if done_file:
    with open(done_file, encoding="utf-8") as f:
        done = {slug(line) for line in f if line.strip()}

with open(path, encoding="utf-8") as f:
    rows = list(csv.DictReader(f))

rows.sort(key=freq, reverse=True)
shown = 0
for row in rows:
    link = row.get("Link") or row.get("URL")
    if slug(link) in done:
        continue
    if skip_easy and row["Difficulty"].lower() == "easy":
        continue
    shown += 1
    print(f"{shown:>3}. {row['Difficulty']:<6} {freq(row):>5.1f}  {row['Title']}  {link}")
    if shown >= limit:
        break
```

### Read company tags with care

- Tags come from user surveys ("have you seen this question in a real interview?"), per LeetCode's own FAQ on the [subscribe page](https://leetcode.com/subscribe/). They show what people practiced and ticked, not exactly what a company asks.
- Two Sum is the number one tag at Google, Meta, Amazon, Microsoft and Bloomberg. Half of Google's 6-month top 10 are LeetCode problems 1 to 10. Filter out Easy problems.
- Small companies have tiny samples: 7 problems in 6 months for Netflix, Flipkart and PhonePe, 12 for Adobe, 14 for Oracle. Use interview reports on the [company pages](../companies/index.md) instead.
- Ignore the "Acceptance Rate" column in the liquidslr files. It is broken (Two Sum shows 0.0058).
- Check commit dates, not README dates. The liquidslr README still says June 2025, but its data was refreshed Aug 16, 2026. Older repos (hxu296, 2022; krishnadey30, 2023) are stale.
- Free company signal without any dataset: [Sean Prashad's site](https://seanprashad.com/leetcode-patterns/) lists companies and frequency for each of its 179 problems.

|---|---|
